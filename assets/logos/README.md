# Institution logos

Logos shown next to each certificate's issuer name in the Certificates section.
They are simple, self-contained SVG badges so the page has zero external logo
dependencies. Replace any of them with the real institution logo (SVG or PNG)
keeping the same filename:

| Filename              | Institution                                        |
|-----------------------|----------------------------------------------------|
| `samsung-sic.svg`     | Samsung Innovation Campus                          |
| `linux-foundation.svg`| The Linux Foundation (used for the Andela course)  |
| `plp.svg`             | Power Learn Project Academy                        |
| `jkuat.svg`           | Jomo Kenyatta University of Agriculture & Technology|

Logos render at 40 × 40 px with `border-radius: 11px` and `object-fit: contain`,
so a square logo works best.
